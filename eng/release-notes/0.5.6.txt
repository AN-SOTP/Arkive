Three additions: Outfit Swap, Game Data mods, and a buttocks height slider in Simple Upscale. None of them has been tried in game yet.

- Outfit Swap (new tab): wear any player outfit in place of another, on any body, for example an Assassin's anniversary outfit as a Slayer's class skin. The outfit is moved onto the other body's skeleton and reshaped with a body difference learned from the game's own costumes; cloth that would sit inside the body is pushed back out. Save as mod saves it through the usual mesh checks. Swapping between male and female bodies is experimental and the shape can be rough. Dyeing a swapped outfit in game does nothing, because its colours are baked into its pictures. Some class skins whose skeleton is only a placeholder are refused, and a swapped outfit may look slightly darker in game than in the preview.
- Game Data mods (Mods > Game tables...): change cells of the game's own tables in data2.lpk as normal mods, such as which model an item shows, which NPCs show a name tag, or camera blur and zoom. Import .sql patch... reads LostArkPatcher-style UPDATE patches. They follow priorities, Apply Plan, Restore all game files and the game-update check like other mods, and share one write of data2.lpk with the Language tab. More actions > Edit table changes... adds table changes to any mod.
- Simple Upscale has a buttocks height slider.
- The Language tab's state moves to the Game Data folder; Arkive moves it over by itself.
