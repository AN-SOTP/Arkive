Two new tabs, Fonts and Language, and a fix for applying colour-only material changes. Neither tab has been tried in game yet.

- Fonts: choose a TrueType font (.ttf) for the game's body text and titles. Arkive rebuilds the game's font file with your fonts in place of its own, for every language. Back to the game's own puts the original file back exactly as it was. Choosing a separate font for damage numbers is included but not yet checked in game.
- Language: show the game's text in Spanish, French or German, including languages the game has removed. Arkive writes the chosen language's lines in place of the English ones, and any line without a translation stays in English. Arkive keeps a copy of every translation, so a language the game later drops can still be used. Back to English puts the game's own file back exactly as it was. Voices are not changed.
- Applying no longer fails on a material that only changes colours, such as a fog colour. Arkive used to ask UModel to check every rebuilt material, and UModel never exports materials without textures, so the package was wrongly refused (for example Holy Kazeros's Final Day fog). Arkive now checks those itself.
